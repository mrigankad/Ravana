The face swap that tells you how good it is.

Ravana swaps faces in photos, video and webcam, and scores every result for identity and sharpness. Compare settings with numbers, not guesses. Works on NVIDIA, AMD and Intel GPUs.

Download for Windows pip install View on GitHub
pip install "git+https://github.com/mrigankad/Ravana.git"

Every result comes with a score.

Other swappers leave you to squint at the output. Ravana measures it, so you can see which setting actually worked.

Identity

ArcFace cosine similarity between the source face and the result. It tells you whether the swap still looks like the person.

Sharpness

Detail gained or lost against the target. It catches restorers that smear the face.

Variants, ranked

Try GFPGAN, GPEN or a 1024 boost in one click and compare them side by side with their scores.

Same inputs, different settings.

Examples from the repo's comparison set. Run ravana evaluate to score your own.

How it works.

Detect, embed, swap, mask, restore and composite. ONNX Runtime throughout, so the same models run on CUDA, DirectML or CPU.

Swappers

HyperSwap 256 for best stills, InSwapper 128 for speed.

Restore and mask

GFPGAN, GPEN, CodeFormer, XSeg occlusion, lighting and colour match.

Realtime

Detect-every-N, ROI tracking and One-Euro smoothing for webcam.

Up and running in a minute.

Python

pip install "git+https://github.com/mrigankad/Ravana.git"            # CPU
pip install "ravana-sdk[gpu] @ git+https://github.com/mrigankad/Ravana.git"       # NVIDIA
pip install "ravana-sdk[directml] @ git+https://github.com/mrigankad/Ravana.git"  # AMD / Intel
python scripts/first_run_check.py --download

Three lines

import cv2
from face_swap import FaceSwapConfig, swap_image

out = swap_image(cv2.imread("source.jpg"), cv2.imread("target.jpg"),
                 FaceSwapConfig(quality="seamless", device="auto"))

CLI

ravana -s source.jpg -t target.jpg -o out.jpg -q seamless
ravana -s source.jpg -t input.mp4  -o out.mp4 -q medium
ravana evaluate -s source.jpg -t target.jpg -o out.jpg

Use it responsibly.
